# 汇川产品刷题工具（Inovance Product Quiz）

面向汇川技术工业自动化产品（**伺服 · 变频器 · PLC · HMI · IO 系统**）的网页版刷题与考核工具。
覆盖 **销售 / 技术 / 采购 / 合作客户** 四类人群，支持六种题型（单选 / 多选 / 判断 / 填空 / 简答 / 场景分析）、多模式刷题、错题本溯源解析、模拟考试、试卷导出与打印、能力数据统计，以及管理端的题库全生命周期管理与考试任务发布。
V2.0 起新增**结构化知识库**：把静态 PDF 变成可检索、可关联刷题的知识条目，解决新人「看文档记不住、没人带、答不上客户」的问题。

- 规划与落地思路：[`docs/开发规划方案.md`](docs/开发规划方案.md)
- 题库数据规范：[`BANK_SCHEMA.md`](BANK_SCHEMA.md)

## 一、快速开始

### 方式 1：直接打开（最简单，无需任何环境）

双击 `index.html` 即可在浏览器中使用；管理后台双击 `admin.html`。

> 题库与学习数据均保存在浏览器本地（localStorage），换浏览器/清缓存会重新开始，可用「个人设置 → 导出数据」做备份。

### 方式 2：本地服务（推荐，体验一致）

```powershell
cd inovance-quiz
node tools/serve.mjs          # 默认 8080 端口
# 刷题端：   http://localhost:8080/index.html
# 管理后台： http://localhost:8080/admin.html
```

### 方式 3：带后端（多端同步 / 服务端判分）

```powershell
# 终端 1：启动后端（Node 24 内置 SQLite，零依赖；首次自动建表 + 导入题库 + 建演示账号）
node server/app.mjs 8090

# 终端 2：启动前端
node tools/serve.mjs 8123

# 浏览器加 ?api=1 进入 API 模式
#   http://localhost:8123/index.html?api=1
#   http://localhost:8123/admin.html?api=1
#   演示账号：admin/Admin@123、trainer01/Trainer@123、engineer01/Engineer@123、
#             sales01/Sales@123、partner01/Partner@123
```

> `server/` 是为联调与自测提供的**零依赖参考实现**（接口契约见 `docs/后端开发规格说明书.md`）。
> 生产环境请按规格书使用 MySQL + Spring Boot；前端切换只需 `?api=1`，页面与交互完全不变。

### 方式 4：企业内网部署

把整个 `inovance-quiz` 目录拷贝到静态服务器即可（无后端、无数据库依赖）。

Nginx 示例：

```nginx
server {
    listen       80;
    server_name  quiz.inovance.local;
    root         /opt/quiz/inovance-quiz;
    index        index.html;

    location / { try_files $uri $uri/ /index.html; }
    location ~* \.(js|css|json)$ { add_header Cache-Control "no-cache"; }
}
```

IIS：新建站点指向该目录，默认文档设为 `index.html`。
若需内嵌企业微信 / 钉钉工作台，把部署地址配置为工作台应用链接即可；单点登录（SSO）为二期企业版能力，接口预留。

## 四、题库维护流程

### 1. 新增 / 修改题目

两种方式：

- **在管理后台直接编辑**：`admin.html → 新增题目 / 题库管理 → 编辑`。改动存在浏览器本地（覆盖内置题或新增自定义题）。
- **改题库源文件（推荐用于团队协作）**：编辑 `data/<品类>.json`，然后重新构建：

```powershell
node tools/build-bank.mjs            # 校验 + 生成 assets/js/core/bank.js
node tools/build-bank.mjs --check    # 只校验不写文件（CI/提交前自检）
```

构建脚本会检查：题号唯一性与格式、品类/题型/难度枚举、答案键是否在选项内、多选题答案数、**填空题答案数组与题干空位数是否一致**、**销售/采购人群是否被误配主观题**，并输出各品类题型与难度分布统计。

人群标识变更（历史 `service` 并入 `engineer`、客观题补 `purchase` 标注）可用迁移脚本自动完成：

```powershell
node tools/migrate-roles.mjs --dry   # 先看会改哪些题
node tools/migrate-roles.mjs         # 写回 data/*.json
```

### 2. 从 Excel 批量导入

1. 在管理后台 `批量导入 / 导出 → 下载 CSV 模板`；
2. 按模板填写（表头：题号,品类,题型,难度,题干,选项A…选项E,正确答案,解析,资料名称,章节,链接,标签,人群,密级）；
3. Excel「另存为 CSV UTF-8」后上传，工具会先校验再入库。

> 填空题的「正确答案」列按空位顺序填写，多个空用 `|` 分隔，例如 `220|基板`。

### 3. 出题要求（摘要，详见 `BANK_SCHEMA.md`）

- 题干中的系列名、型号、参数必须真实存在，以汇川官方手册/官网为准；
- 每题必须写解析（说明干扰项错在哪）与资料溯源；
- 难度分布建议：初级 40% / 中级 40% / 高级 20%；
- 密级：`public` 可对客户公开、`internal` 仅内部、`confidential` 仅超管与讲师；
- **题型**：`single` / `multi` / `judge` / `fill` / `short` / `scenario`；销售与采购人群只能用前四种客观题。

## 五、权限与密级

| 角色 | 权限概要 |
|------|----------|
| 超级管理员 `super_admin` | 全部功能；题库全生命周期管理；可见涉密题库与全部报表；**试卷导出 / 打印** |
| 培训讲师 `trainer` | 题库维护与审核、批量导入、发布考试任务、团队报表；**试卷导出 / 打印** |
| 内部员工 `employee` | 内部题库刷题与考试、个人数据统计 |
| 代理商/客户 `partner` | 仅公开题库（对外赋能版）、被指派的考试任务、个人数据 |

题库密级为 `confidential`（涉密）的题目对 `partner` 角色**在数据加载层即被过滤**，不会下发到前端。
试卷导出 / 打印面板按 `task.write` 权限显示，仅超级管理员与培训讲师可用；组卷只使用当前账号可见密级的题目。
身份切换：刷题端右上角头像 → 切换身份，或在登录页直接选择。

## 六、常见问题

**Q：数据存在哪里？会不会丢？**
本项目一期为纯前端实现，数据保存在浏览器 localStorage（键名 `iqz.state.v1`）。换设备、换浏览器、清理浏览器数据都会丢失，建议定期在「个人设置 → 导出全部数据」备份。二期企业版将数据落到数据库，可多端同步。

**Q：为什么管理端的报表只有本机数据？**
单机版没有服务端，报表只能统计当前浏览器中的数据。企业版接入后端后，可按团队 / 个人 / 题库多维出数（页面结构已按此预留）。

**Q：题库文件很大，会不会卡？**
一期按 3000 题量级设计：列表分页渲染、答题只重绘题卡、图表为轻量 SVG。若题库继续增长，建议二期改为按需加载（按品类拆分 bank 文件）或后端分页查询。

**Q：导出的 Word 打不开 / 格式错乱怎么办？**
**Q：知识库的「导出 PDF」为什么打开的是打印对话框？**
因为要同时满足「零依赖 + 内网离线 + 中文排版」三个约束：真正的 PDF 生成库必须内嵌中文字体子集（通常数 MB），会显著增加体积、破坏离线包的精简性。所以导出走**浏览器原生打印管线**——在弹出的对话框里把「目标打印机」选为 **「另存为 PDF」/「Microsoft Print to PDF」** 即可保存成 PDF 文件。
PDF 的默认文件名已自动填好（形如 `汇川知识库_KB-SRV-001_sv660n型号怎么读.pdf`）；建议顺手关掉对话框里的「页眉和页脚」，版面会更干净。
导出的 PDF 保留浅色底纹（提示框、话术对比、表头），已声明 `print-color-adjust: exact`。

**Q：试卷导出和知识库导出是同一套机制吗？**
是。两者都走**浏览器打印管线**产出 PDF（在打印对话框中选择「另存为 PDF / Microsoft Print to PDF」），零依赖、中文由浏览器渲染。
试卷的 PDF 默认文件名形如 `汇川产品知识测评试卷_销售采购人员_EX-20260915-0749.pdf`，教师卷会带 `_含答案` 后缀；知识条目则是 `汇川知识库_<编号>_<标题>.pdf`。

**Q：能内嵌企业微信 / 钉钉吗？**
可以。把部署地址配置为工作台应用链接即可；单点登录（免登）需二期接入企业微信/钉钉开放平台与 CAS/OAuth2。

## 七、技术说明

- **纯静态**：无框架、无构建、无外部 CDN 依赖，内网离线可用；
- **设计语言**：**Material You（Material Design 3）**，种子色 = 品牌蓝 `#0b5cab`；
- **设计令牌**：`assets/css/md3-tokens.css` 由 `tools/gen-md3-tokens.mjs` 从种子色推导生成（参考调色板 → 语义令牌 → 浅/深两套）。**换品牌色只需改脚本里的 `SEED` 常量并重跑**，组件层无需改动；
- **接入方式**：`main.css` 顶部的「兼容映射层」把既有变量（`--brand` / `--card` / `--text` …）指向 MD3 语义令牌，因此全部现有组件零改写即获得 Material You 配色；深色模式完全由令牌驱动（`body.dark` 重定义语义令牌），组件层不再有任何夜间硬编码色；
- **模块划分**：`store.js`（数据与权限）→ `engine.js`（业务引擎）→ `ui.js`（通用组件）→ `paper.js`（试卷导出）→ `app.js` / `admin.js`（页面）；
- **可升级性**：数据层集中封装，二期替换 `store.js` 为后端 API 适配层即可复用全部页面代码；
- **兼容性**：ES5+ 语法（不使用可选链等新特性），适配内网老版本浏览器内核；响应式断点 900px / 560px，最小适配宽度 360px。

## 八、打包与分发（可移植交付）

需要把工具交给别人（培训同事、代理商、内网运维）时，执行一条命令生成可分发的产物：

```powershell
node tools/package.mjs            # 生成到 inovance-quiz/dist/
node tools/package.mjs --clean    # 先清空 dist/ 再生成
```

产物说明：

| 产物 | 大小 | 适用场景 |
|------|------|----------|
| `dist/汇川产品刷题工具-单文件版.html` | ≈ 940 KB | **零依赖**：题库、样式、脚本全部内联，双击即用（`file://` 亦可），适合微信/邮件直接发 |
| `dist/汇川产品刷题工具-管理端-单文件版.html` | ≈ 900 KB | 同上，管理后台版本 |
| `dist/inovance-quiz/` | ≈ 2 MB | 完整可移植目录（含后端参考实现、构建工具、题库源文件、文档），附 `快速开始.txt` |
| `dist/汇川产品刷题工具-便携版-<日期>.zip` | ≈ 1.1 MB | 上述三者的压缩包，一次拷走 |

打包时自动排除运行时文件（`server/quiz.db*`、日志、`node_modules`、`dist/` 自身），
因此便携包首次启动后端会**自动建库并导入 986 题 + 创建演示账号**，无需手工初始化。

单文件版与完整目录均支持两种模式：默认本地模式（数据存浏览器 localStorage）；
在地址后加 `?api=1` 即切换为后端模式。
